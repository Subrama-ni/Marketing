# 📈 Marketing Platform

## 📌 Overview

Marketing Platform is a full-stack web application designed to help businesses and marketing teams efficiently manage marketing activities, track performance, and monitor commissions through a centralized platform.

The application provides secure authentication, role-based access, campaign and sales management, commission calculation, payment history, and performance insights through an intuitive dashboard.

The main objective of the Marketing Platform is to provide a centralized and scalable solution for managing marketing operations, tracking commissions and payments, and analyzing business performance.
